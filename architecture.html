Architecture

What actually runs on your machine.

A local Python control plane opens real terminals, keeps its state in SQLite and serves one React interface.

Process model

A local backend manages each process.

The interface sends commands. The backend owns the agent processes and their state.

Event flow

Events are written to SQLite first.

Then they reach the subscribers, interface and webhooks that listen.

  • task board
  • sessions
  • pipelines
  • access

Worktree isolation

Separate worktrees keep edits apart.

Off by default. Claude Code sessions can opt in.

Without a worktree, edits are checked.

If another active session recently edited the same file, IVE blocks the edit and asks the agent to check the diff.

API and extensions

The backend is available outside the UI.

Scripts, agents, hooks and extensions can use the same local control plane.

API
Drive sessions and read local state from code.
MCP tools
Start sessions, assign tasks and read their output over MCP.
Events
Subscribe to changes or forward them by webhook.
Plugins
Install extensions from registries and attach MCP servers per session.

Security

Checks run before execution.

A hook checks each tool call against built-in deny rules.

AVCP · supply chain
Optional and off by default. When on, it checks pip, npm and other package installs before they run.

API write requests are logged in SQLite with sender, mode and IP address.
