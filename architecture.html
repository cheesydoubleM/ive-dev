Architecture

What actually runs on your machine.

A local Python control plane opens real terminals, tracks every state change in SQLite, and exposes the operation to one React interface.

Process model

A local backend manages each process.

The interface sends commands. The backend owns the agent processes and their state.

Event flow

Every state change is recorded once.

The same ordered event is then sent to subscribers, the interface, and webhooks.

  • session lifecycle
  • tool execution
  • subagent spawning
  • compaction

Worktree isolation

Separate worktrees prevent overwritten files.

Each agent starts in its own working copy.

One worktree per agent.

Each session works in its own git worktree. Branch state stays scoped to that process.

Structured CLI hooks report lifecycle and tool activity as they happen.

Security

Checks run before and during execution.

Account isolation and audit records are part of the runtime. The package scan is optional.

AVCP · supply chain
Optional and off by default. When turned on, it intercepts pip, npm, and GitHub Actions and runs a 9‑step package scan before execution.
HOME · account sandbox
Each OAuth account gets a separate sandboxed HOME directory. Cookies do not cross account boundaries.
EVENT · audit trail
Session, tool, subagent, and compaction changes persist to SQLite before delivery.
