  2. IVE’s configured pipeline records the failure and supplies its details to the next attempt. State is persisted in SQLite before delivery to subscribers, WebSocket clients, and webhooks.

HOW IVE WORKS

From one goal to one review.

GOAL → PLAN → WORK → CHECK → REVIEW

GOAL — Describe the change you want.

PLAN — IVE turns the goal into focused tasks.

WORK — Each agent gets its own task and workspace.

WATCH — Follow every task from one screen.

CHECK — Failed checks are fixed and tried again.

RESULT — Completed changes come back together.

REVIEW — You decide what gets merged.

WHAT IVE HANDLES

IVE coordinates the parallel work.

It splits the goal into tasks, keeps sessions separate, retries failed checks, and brings the changes back for review.

OVERVIEW

See every session in one place.

IVE shows what is running, what is waiting, and which task needs your input.

TASKS

Split one goal into separate tasks.

Describe the change. IVE creates focused tasks, starts the sessions, and keeps overlapping work from colliding.

IVE spotted two tasks changing the same file and rerouted one before anything was overwritten.

RETRIES

Retry failed checks automatically.

When a test fails, IVE can return the task for another attempt. It asks for your input when the failure needs a decision.

CONTEXT

Pass useful context between sessions.

New sessions receive relevant notes from earlier work. The final summary records what changed and what still needs review.

WHAT YOU BRING

IVE done it for you.
Bring your own models. Bring your own tokens.

Every session is a real terminal inside the app, running the coding CLI you already have, on your own account.

TERMINAL

The terminal lives in the app.

Every session runs in a real terminal inside IVE, and the CLI behaves the way it does anywhere else. Press ⌘J to open it, type into it, and read what the agent is doing as it happens.

YOUR MODELS

Bring the models you love most.

IVE adds no model access of its own. It starts the Claude Code, Codex, or Gemini CLI on your machine, and you pick the model per session: Haiku, Sonnet, Opus, Gemini Pro, or Flash. Say Opus for the backend and Haiku for the review, and switch when the work changes. What is available depends on your installed CLI and your provider account, not on IVE.

See models and modes ↗

YOUR TOKENS

Sessions run on your own accounts.

Sessions run on the CLI accounts and plans you already have. When IVE itself asks a model for something, like the short catch-up summary, that goes through your CLI as well, or through an API key you enter under Settings → Model Providers. The key is stored in IVE’s local settings on your machine.

A few things to know

Before you
come aboard.

Are the demos recordings of the real app?+

Yes. They were recorded from IVE’s actual application frontend on an isolated test transport. The Orbit project, session names, and conversation content were prepared for this tour; no AI provider ran. The animated scenes on this page are illustrations.

Can I use IVE today?+

Yes. IVE is open source under the Apache 2.0 license. Install it with one command or clone it from GitHub. You need macOS or Linux and Claude Code, Codex, or Gemini CLI.

Which agents can I use?+

IVE works with Claude Code, Codex, and Gemini CLI. The recordings show Claude Code and Codex side by side. Available models and features depend on your installed CLI and provider account.

Does everything stay on my machine?+

IVE’s desktop workspace runs locally. Using an AI provider can send prompts, context, and code to that provider. Local execution does not mean the model runs offline.

What platform is shown here?+

The recordings show IVE on macOS. You can install it on macOS or Linux.

GET IVE

Install IVE
with one command.

IVE is open source under the Apache 2.0 license. It installs on macOS and Linux and runs on your machine.

If IVE is useful to you, give it a star on GitHub.

Install
$ curl -fsSL https://ive.dev/install.sh | bash

Then start IVE with: ive

The installer puts the code in ~/.ive, installs its dependencies, builds the app, and adds the ive command to ~/.local/bin. Read the script first on GitHub

Requirements macOS or Linux, Python 3.11+, Node.js 22.12+ with npm, Git, and at least one coding CLI you already use: Claude Code · Codex · Gemini CLI.
