GOAL — Describe the change you want.

PLAN — IVE turns the goal into focused tasks.

WORK — Each agent gets its own task and workspace.

WATCH — Follow every task from one screen.

CHECK — Failed checks are fixed and tried again.

RESULT — Completed changes come back together.

REVIEW — You decide what gets merged.

WHAT IVE HANDLES

IVE coordinates the parallel work.

It splits the goal into tasks, keeps sessions separate, retries failed checks, and brings the changes back for review.

OVERVIEW

See every session in one place.

IVE shows what is running, what is waiting, and which task needs your input.

TASKS

Split one goal into separate tasks.

Describe the change. IVE creates focused tasks, starts the sessions, and keeps overlapping work from colliding.

IVE spotted two tasks changing the same file and rerouted one before anything was overwritten.

RETRIES

Retry failed checks automatically.

When a test fails, IVE can return the task for another attempt. It asks for your input when the failure needs a decision.

CONTEXT

Pass useful context between sessions.

New sessions receive relevant notes from earlier work. The final summary records what changed and what still needs review.

Merge

Every session comes back as one review.
