Mac app

Download for Mac

Apple silicon (M1 or newer) · macOS 13.5 or newer

Open the disk image and drag IVE into Applications. The app runs its own local service in the background: no terminal window, no browser tab, one app in the Dock. You need at least one coding CLI you are signed in to: Claude Code, Codex or Gemini (Antigravity CLI). The app is signed by AIFOREU GmbH and notarized by Apple. The SHA-256 is on the releases page.

Release notes on GitHub (opens in a new tab)

Terminal

curl -fsSL https://ive.dev/install.sh | bash

Then start IVE with ive. It runs in the background and opens http://127.0.0.1:5111; you can close the terminal. ive stop stops it; ive status, ive logs and ive update do what they say; ive uninstall removes it. The installer puts the code in ~/.ive, installs its dependencies, builds the app and adds the ive command to ~/.local/bin. It does not use sudo.

Questions

Which agents work with IVE?

Claude Code, Codex and Gemini (Antigravity CLI). Available models depend on your installed CLI and provider account.

Does the model run locally?

IVE runs on your computer and listens on 127.0.0.1 by default. Your coding CLI still sends prompts, context and code to the provider you use, as it does without IVE.

Which platforms?

The Mac app runs on Apple silicon with macOS 13.5 or newer. The terminal install works on macOS (including Intel Macs) and Linux. There is no Windows version.

How do I remove it?

Terminal install: ive uninstall. Mac app: quit it, run "/Applications/IVE.app/Contents/Resources/backend/ive-backend" --remove-hooks, then delete the app.
